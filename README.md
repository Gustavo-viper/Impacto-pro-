# Impacto Pro Orçamentos — V15

## Checklist de carregamento
- Todo equipamento cadastrado no Estoque aparece na conferência geral do Checklist.
- Ao salvar um orçamento, os equipamentos selecionados são automaticamente enviados ao Checklist de carregamento.
- Cada item do orçamento aparece com quantidade + nome + local do evento, por exemplo: `1x Grave — Mercereto`.
- O endereço/cidade e dados do evento ficam associados à lista de carregamento.
- Cada linha possui um checkbox grande para marcar o item como `OK` ao carregar na van.
- O progresso de cada orçamento é mostrado como `X/Y OK`.
- Se um orçamento for editado, a lista de carregamento daquele orçamento é atualizada e os itens já marcados como OK permanecem marcados quando o equipamento continua no orçamento.
- O funcionamento permanece local/offline.
