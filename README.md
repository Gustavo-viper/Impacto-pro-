# Impacto Pro Orçamentos — V16

Checklist de carregamento integrado ao Estoque e aos Orçamentos.

- Todo equipamento do estoque aparece automaticamente no Checklist.
- Ao abrir o Checklist, orçamentos antigos também são sincronizados automaticamente.
- Cada unidade selecionada no orçamento ganha seu próprio checkbox de carregamento.
- Exemplo: 3 Graves geram 3 linhas: Unidade 1/3, 2/3 e 3/3.
- Cada item leva automaticamente o local, cidade, evento, data e horário do orçamento.
- O botão OK fica disponível para marcar cada unidade conforme entra na van.
- Alterações no orçamento preservam as marcações das unidades que continuam selecionadas.
- Mantido funcionamento offline e identidade do Impacto Pro.
